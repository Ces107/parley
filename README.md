# Parley

Three ninety-minute conversation games for three or four advanced speakers of English. Open one on a shared screen; each player scans a code with their phone.

- **The Council**: govern a tiny new island state for a year. Every crisis is based on something that really happened to a small country.
- **The Leak**: a confidential note reached a newspaper. Work out who sent it from six exhibits, then decide whether they were right.
- **The Panel**: four rounds in the manner of British radio panel shows, with phones as buzzers.

Static site, no build step. `node tools/check.js` checks the content and simulates play.

Live at https://cesio.es/parley/
